# Layout 家族原型

建立日期：2026-09-09  
最後更新：2026-09-09

---

Structured Layout 原型用來檢驗三種溝通職能——Weekly Overview、Evidence-backed Decision、Next Actions——能否共用同一套編輯式外框，同時在畫面上仍可分辨。它驗證的是構圖與層級，不是生產就緒。

## 它是什麼

可拋棄的獨立 Vite 入口，路徑為 `/prototype.html`。範例文案全部寫死。Gallery 縮圖與 focused 16:9 畫面沿用既有 Stage 色彩與字體 token。

## 視覺通過不代表什麼

原型視覺通過，並不授權下列事項：

- 新增生產用 `layout` 值，或改 Week Page schema
- 工坊編輯表單
- 這些頁面的 PNG 匯出
- 取代 `two-column`，或改動 HTML Page
- 中文或中英混排的排版驗證
- 第二套視覺主題

理想化英文稿刻意拿掉篇幅變異。後續若進生產，必須用真實週報長度、schema 限制、編輯器行為與匯出來壓力測試。

## 隔離

工坊殼沒有連到此原型。既有週次文件與生產 Stage layout 未改。是否接進生產，需在視覺驗證後另作決定。
