# 隱藏不需匯出的頁面

建立日期：2026-08-31  
最後更新：2026-08-31

---

## 步驟

1. **Page** 選擇要隱藏的頁面
2. 勾選 **Hide page from export**
3. 點 **Save**

## 效果

| 行為                  | hidden 頁面                                              |
| --------------------- | -------------------------------------------------------- |
| 左側編輯器            | 仍可選取、修改；**Page** 下拉顯示 `(hidden)`             |
| 16:9 預覽             | 仍可預覽該頁                                             |
| **Download PNGs**     | 略過                                                     |
| **Copy to clipboard** | 若目前預覽為 hidden 頁，仍可複製該頁（複製的是當下預覽） |

## 取消隱藏

取消勾選 **Hide page from export** 並 **Save**。
