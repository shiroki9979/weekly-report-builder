# 新增、刪除與重排頁面

建立日期：2026-09-10  
最後更新：2026-09-10

---

## 新增頁面

1. 解鎖 **Edit**
2. 在 **Add page** 選擇 layout（Two-column、Weekly Overview 或 Evidence-backed Decision）。Two-column 再選 panel（Table / Chart / Flow / Checklist）
3. 點 **Add page**

新頁會插在目前選取頁之後並立即被選取。內容為空白草稿，可 Save，但尚未填完前不能 Copy 或進入批次匯出。

## 重排

使用 **Move up** / **Move down**。到達首尾時該方向按鈕會停用。選取跟隨 Page ID，不會因為重排而跳到別頁。

## 刪除

1. 選取要刪的頁
2. 點 **Delete page**
3. 確認對話框中的 title 與 layout 後點 **Delete**

不能刪除 Week Document 的最後一頁。刪除只改本地 state，仍須 **Save** 才寫入檔案。
