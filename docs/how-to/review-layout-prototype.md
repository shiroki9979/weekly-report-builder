# 檢視 layout 原型

建立日期：2026-09-09  
最後更新：2026-09-09

---

開啟可拋棄的 Structured Layout 原型，以 16:9 檢視三種溝通職能頁。

## 步驟

1. 啟動工坊：`pnpm dev`
2. 在同一 origin 開啟 `/prototype.html`（例如 `http://localhost:5173/prototype.html`）
3. 在 Gallery 比較三個縮圖：Weekly Overview、Evidence-backed Decision、Next Actions
4. 點任一縮圖，進入對應的 focused 16:9 頁
5. 用 **Back to gallery** 回到比較畫面

檢視層級時，將 focused Stage 調到約 800 × 450。

## 目視標準

五秒內應能看出該頁職能與結論。標題與主要數字需可讀。範例文案不應溢出或斷行怪異。三頁應像同一家族、職能可辨，且各有一個主導視覺錨點。

2026-09-09 的 800 × 450 審查結果見 [Layout 家族原型](../explanation/layout-prototype.md)。

## 注意

此入口未接上工坊。視覺通過不是生產就緒；見 [Layout 家族原型](../explanation/layout-prototype.md)。
